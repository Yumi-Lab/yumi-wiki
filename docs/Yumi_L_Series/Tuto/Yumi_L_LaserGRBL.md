# Laser GRBL

## 1. LaserGRBL: Free, Powerful, and Easy to Use

[![LaserGRBL logo](/img/Yumi_L_Series/Tuto/lasergrbl-software.jpg){ width="350" }](https://lasergrbl.com/download/)

Unlike many expensive engraving programs, LaserGRBL is:

- Free and open-source
- Compatible with the Yumi L-A4
- User-friendly
- Supports multiple file formats (JPG, PNG, SVG...)

The perfect choice to get started without investing in paid software.

## 2. Prepare and Test Your Engraving

1. [Download and install LaserGRBL](https://lasergrbl.com/download/), then connect your Yumi L-A4 to your PC.

    ![LaserGRBL download page on lasergrbl.com](/img/Yumi_L_Series/Tuto/lasergrbl-download.jpg){ width="320" }

2. Place your material and adjust the laser head height using the included guide.

    ![Yumi L-A4 laser head lowered onto the material with the height guide](/img/Yumi_L_Series/Tuto/lasergrbl-height-guide.jpg){ width="320" }

3. Connect the Yumi L-A4 and run a test engraving.

    ![LaserGRBL Grbl menu with the Connect entry highlighted](/img/Yumi_L_Series/Tuto/lasergrbl-connect-test.jpg){ width="320" }

4. Perform a burn test.

    ![LaserGRBL Generate menu with the Power vs Speed test entry highlighted](/img/Yumi_L_Series/Tuto/lasergrbl-burn-test.jpg){ width="320" }

5. Adjust the size based on your material (in mm).

    ![Power vs Speed test generator dialog with the size fields highlighted](/img/Yumi_L_Series/Tuto/lasergrbl-size.jpg){ width="320" }

6. Position the laser head so it starts from the bottom-left corner of the engraving area.

    ![Laser head positioned at the corner of a cork disc on the honeycomb bed](/img/Yumi_L_Series/Tuto/lasergrbl-origin-position.jpg){ width="320" }

7. Start the test engraving.

    ![LaserGRBL preview of the power/speed test grid with the run button highlighted](/img/Yumi_L_Series/Tuto/lasergrbl-start-test.jpg){ width="320" }

8. The ideal settings produce a black, clean, and even engraving — without burning or digging into the material. Keep notes of your best parameters for future projects.

    ![Cork disc engraved with the power/speed test grid, best result highlighted](/img/Yumi_L_Series/Tuto/lasergrbl-result-settings.jpg){ width="320" }
